# 犬子老師・台股飆股雷達 Free Edition v1.1

這版把你要求的 **籌碼 + 大盤走勢** 正式納入雷達總分。

## 新總分 100 分

- 技術：50
- 籌碼：25
- 族群：10
- 大盤：15

### 籌碼 25 分
- 外資連 3 買：最高 8
- 借券賣出餘額連 3 減：最高 7
- 投信：最高 5
- 融資健康度：最高 5

如果某項官方資料暫時抓不到，系統用「中性分」而不是硬扣 0 分，並保留 `chip_coverage_pct` 讓前端知道資料完整度。

### 大盤 15 分
- 加權趨勢：最高 5
- 櫃買趨勢：最高 4
- 上漲家數比：最高 3
- 全市場外資方向：最高 3

大盤會分：
- 偏多：剛啟動門檻 70
- 中性：門檻 76
- 防守：門檻 82

所以同一檔股票，在弱勢大盤不會跟強勢大盤用完全相同的門檻。

## 排程拆開

為了維持 0 月費又不要每 5 分鐘重抓全市場：

- `close.yml`：台灣時間約 14:25 跑全市場日K + 籌碼 + 大盤
- `intraday.yml`：交易時段每 5 分鐘只抓固定關注股 + 前一盤後雷達前 150 名

盤中 workflow 會先從目前 GitHub Pages 把上一份盤後 JSON 抓回來，所以不需要每次重跑全部籌碼。

## 資料說明

盤中的外資、投信、融資、借券，使用「最近已完成交易日」資料。
程式不會把今天尚未公布的盤後籌碼冒充成即時籌碼。

- 首頁最上方「市場環境」
- 每檔顯示四塊分數：技術 / 籌碼 / 族群 / 大盤

編輯 `config/watchlist.txt`，一行一個股票代號。
